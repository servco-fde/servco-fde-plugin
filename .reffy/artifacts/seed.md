# seed init

Here's what I want to do. This repo is intended to become a reusable tool powered by the two powerful standards emerging to control agentic development/workflows: skills and plugins:
https://agentskills.io/specification
https://agent-plugins.org/specification

I'm convinced that applying these two standards within a repo that can be easily accessed by our Forward Deployed Engineers will allow us to radically simplify onboarding and supporting non-technical FDEs into a Full Stack Engineering workflow for internal applications. I want you to use the specifications I provided to help me stub out the initial files we will need to serve as an agentic helper tool for new and existing FDEs on our team that will be primarily deploying applications into Databricks Apps and also using Azure DevOps for CI/CD as well as looking forward to future platform integrations with Microsoft Graph API and maybe others as the need arises. Go ahead and create the initial file structure that's needed for an agent plugin/skills of this nature.
