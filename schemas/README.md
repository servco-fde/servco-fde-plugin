# Schema provenance

These are formatting-normalized copies of the official Agent Plugins 1.0.0 schemas, retrieved from the published documentation on 2026-10-19:

- [plugin.schema.json](https://agent-plugins.org/schemas/1.0.0/plugin.schema.json)
- [mcp.schema.json](https://agent-plugins.org/schemas/1.0.0/mcp.schema.json)

They are bundled for offline validation. Update the schema files, manifest identifiers, and validator together when deliberately adopting a new specification version. The [specification text](https://agent-plugins.org/specification) remains authoritative; JSON Schema validation alone does not cover all runtime or semantic requirements.
